Tiny Pawns is a chess engine in under 4 KB of Python. It plays with a
negamax alpha-beta search: quiescence with delta pruning, a transposition
table, PVS, late move reductions, null-move and reverse futility pruning,
check extensions, and killer/history move ordering. The board is a
120-character string always kept from the side-to-move's point of view,
and the piece-square tables are generated by formula instead of stored,
which keeps the packed file small. One fixed node budget per move (no
clock reads) makes every game deterministic and replayable.

`main.py` is the packed entrypoint (LZMA) produced by the make.fun
kit's compress command from the readable source.

## Run it

```sh
MAKEFUN_ENV_URL=<environment url> python3 main.py
```

The engine talks to the environment over HTTP: it asks for a game,
answers each position with a move, and stops when the match is done.
